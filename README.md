# 🌐 HoloSpace — Collaborative 3D Workspace

A real-time collaborative virtual workspace for interacting with 3D objects, sharing ideas, and working together online.

## 🚀 Live Demo
[**https://holo-space-u2f5.vercel.app**](YOUR_LIVE_DEMO_URL)

## ✨ Features
- 🧊 Interactive 3D workspace
- 📝 Collaborative whiteboard and sticky notes
- 👥 Shared rooms for team collaboration
- 🔄 Real-time synchronization using WebSockets
- 💾 Persistent room data storage
- 🌍 Browser-based access

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Three.js, JavaScript, CSS
- **Backend:** Java 17+, Spring Boot, WebSockets
- **Database:** PostgreSQL / H2
- **Deployment:** Vercel, Render

## ⚙️ Run Locally

**Backend**
```bash
cd backend
mvn spring-boot:run
```

**Frontend** (open a second terminal)
```bash
cd frontend
npm install
npm run dev
```

Open: http://localhost:5173
